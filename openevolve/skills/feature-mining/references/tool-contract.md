# Feature-mining tool contract

Keep the data utility focused on CSV import and read-only DuckDB inspection/querying.

## Data interface

```python
class CsvDuckDBTool(Protocol):
    def create_database(self, csv_path: str) -> DatabaseResult: ...
    def import_csv(self, csv_path: str, table: str | None = None) -> ImportResult: ...
    def describe(self, csv_path: str, table: str) -> TableMetadata: ...
    def query(self, csv_path: str, sql: str, max_rows: int = 100) -> QueryResult: ...
    def drop_table(self, csv_path: str, table: str, confirm: bool = False) -> DropResult: ...
```

Every operation accepts the CSV path and opens/closes its own connection to `<csv-directory>/<csv-stem>.duckdb`. `create_database` creates/connects to that file. `import_csv` creates a table named from the CSV filename, adds an `id` column, and imports all rows. `describe` returns table schema and row count. `query` is read-only SQL for metadata and statistics. `drop_table` requires explicit confirmation. The reference implementation is `scripts/csv_duckdb.py`; it uses one DuckDB database and does not expose arbitrary shell or DDL operations to the model.

## Knowledge interfaces

Knowledge maintenance accepts either one Markdown file or a directory. A file update is incremental and never archives unrelated documents. A directory sync is recursive and may archive indexed documents missing from that directory.

```python
class KnowledgeManager(Protocol):
    def scan(self, path: str) -> ScanResult: ...
    def validate(self, path: str) -> ValidationResult: ...
    def sync(self, path: str, mode: Literal["check", "draft", "publish"] = "check") -> SyncResult: ...
    def rebuild_index(self, path: str) -> IndexResult: ...
```

The reference implementation is `scripts/knowledge_manager.py`. It recursively reads Markdown front matter, detects added/updated/unchanged files by content hash, writes `index_by_id.json`, `index_by_tag.json`, `index_by_trigger.json`, and `manifest.json` atomically, and keeps errors from entering a published index.

```python
class KnowledgeStore(Protocol):
    def toc(self, domain: str | None = None, max_depth: int = 2) -> list[KnowledgeNode]: ...
    def search(self, query: str, domain: str | None = None, top_k: int = 5, max_level: int = 1) -> list[KnowledgeHit]: ...
    def open(self, document_id: str, level: int = 1, sections: list[str] | None = None) -> KnowledgeDocument: ...
    def expand(self, document_id: str, children: bool = True, max_items: int = 5) -> list[KnowledgeNode]: ...
    def cite(self, document_ids: list[str]) -> list[KnowledgeCitation]: ...
```

Keep tool output JSON-serializable, compact, and source-addressable. Every response should include an ID, version, provenance, and truncation status where applicable.

## Error contract

Return typed errors: `invalid_csv`, `invalid_table`, `table_not_found`, `unsafe_query`, `result_limit`, and `resource_limit`. Never convert these into an empty successful result.
